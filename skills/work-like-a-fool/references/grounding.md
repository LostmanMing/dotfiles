# 锚定真实环境：这套方法最重要的一条

**教程的价值 90% 来自「在学习者的真实环境里跑过」。** 未经验证的内容看起来一样，
但会在学习者第一次动手时崩掉，然后他会放弃整个教程。

## 1. 开工前：探测环境

```bash
python3 scripts/probe_env.py                                  # 通用
python3 scripts/probe_env.py --python /path/to/venv/bin/python # 指定解释器查包
python3 scripts/probe_env.py --extra "自定义探测命令"
```

把结果原样写进站点首页的「本机环境」小节。**凡是有歧义的地方必须在课程里写明用哪一个**：
同一工具装了多个版本、多个运行时/解释器、多套配置文件 —— 这些歧义几乎必然导致学习者踩坑。

## 2. 铁律：核对接口，不要凭记忆写

任何一个函数签名、字段名、返回类型、配置项、命令行参数，都要在**目标环境的真实源码/头文件/
帮助输出**里核对过再写进课程。版本漂移是教程最大的错误来源。

```bash
# 读源码/头文件而不是凭印象
grep -n "关键符号" <安装路径>/...
sed -n '起,止p' <文件>

# 读运行时而不是读文档（文档常年过期）
<解释器> -c "查询接口签名 / 列出可用成员"
<CLI> --help    |    <CLI> <子命令> --help
```

典型教训：凭记忆写下的返回类型/默认值/生效范围，与目标版本的实际实现有出入，
学习者照抄后代码直接崩或行为不符。**先查再写，永远不亏。**

两条核实途径并用：**本地源码/运行时**（当前环境的事实）+ **`WebSearch`**（官方文档、
版本变更、社区已知坑）。涉及版本差异或最佳实践时，用当前年份做关键词搜最新信息，
并记下可信来源写进课程的引用。

## 3. 铁律：动手环节必须真跑一遍

每个动手环节（lab）都要在写进课程**之前**实际执行，把**真实输出**贴进 `<div class="real">`。

真实输出的三重价值：
1. 证明命令能跑通（路径、参数、版本都对）
2. 学习者有对照基准，跑出不一样就知道环境有差异
3. 真实数字往往**推翻你的预设**——那正是最有价值的教学内容

只要出现「实测数字和我预期的不一样」，就停下来查清楚，并把这个差异突出写进课程——
预设被推翻的地方，往往正是学习者最容易犯错、最需要被点醒的地方。

## 4. 把踩到的坑写成课程内容

调试过程中每一个「卡了十分钟才发现」的问题，都是高价值内容。**尤其是静默失败**
（不报错、只是结果不对、为空、或异常地慢）——学习者独自遇到时会卡很久。

常见的几类静默失败，值得主动去撞一撞、然后写进课程：
- **工具/依赖版本与环境不匹配**：命令看似成功、产物正常生成，但内容为空或缺失。
  → 教诊断方法（去哪看日志/诊断表/退出细节），而不只是给结论。
- **构建/编译选项与依赖库不一致**：不崩，只是行为诡异或性能暴跌若干倍。
- **测量手段干扰了被测对象**：加了观测就改变了结果，于是得出错误结论。
  → 由此提炼出通用原则，比就事论事更有价值。

写法：`<div class="real">` 里先写现象，再写根因，再写解决，最后写一句「教训/通用原则」。

## 5. 交叉验证

同一个量用两种独立方式测，对不上就说明理解有误。这是发现自己错误最有效的手段。

把这类「两条路应当得到一致结果」的校验，做成课程里的**验收标准**——
给学习者一个明确的「做对了没有」的判据，而不是让他自己猜。

## 6. 装东西之前先测网速与兼容性

```bash
curl -sS -m 6 -o /dev/null -w "%{http_code} %{speed_download}B/s\n" <包源 URL>
```

若默认源慢或不可达，**把可用的镜像/加速方式写进课程**，否则学习者第一步就卡住
（常见：语言包管理器源、系统包管理器源、模型/数据集下载源等）。

另外注意**依赖与底层平台的兼容**：默认安装的最新版可能绑定过新的底层组件，
而目标机器的驱动/运行时/系统库偏旧。装之前先确认版本约束，装完**立刻用一行命令验证可用性**，
不要等到课程写完才发现装错了。

## 7. 无法真跑时怎么办

如果某部分确实跑不了（缺硬件、缺权限、依赖装不上、涉及生产系统）：

- **明确标注**「本节未在本机验证，需按你的版本核对」，不要混进实测内容里。
- 给出**验证命令**让学习者自己核对，而不是直接给一个可能过期的结论。
- 优先给「怎么查」而不是「是什么」——版本会变，查法不会。
