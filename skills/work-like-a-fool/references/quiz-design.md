# 出题方法论

测评的目的**不是打分**，是画出学习者的知识边界，好决定哪些内容可以跳过、哪些必须从零讲。
一道设计好的题，答错和答对都能提供信息。

## 1. 先拆维度，再出题

从任务目标反推出 4–7 个**知识维度**，每个维度对应技术链路上的一段。维度必须是
「能独立评估、且缺失后会导致任务失败」的东西。

反例（太笼统，答完不知道该讲什么）：`基础知识` / `编程能力` / `工具使用`

正例的特征：每个维度对应「任务技术链路上的一段」，彼此不重叠，且缺任何一段任务都做不成。
维度数据结构：`const CATS = { key: { name: "维度名" } }`，key 用简短英文小写，name 用中文。
拆维度时按「从用户入口到底层实现」的链路走一遍，链路的每一段就是一个候选维度；
再砍掉那些「就算不懂也不影响这个任务」的段，剩下的 4–7 个就是测评维度。

## 2. 题量与分布

- 总量 **20–26 道**。少于 20 分辨率不够，多于 26 学习者会放弃。
- 每个维度 **≥ 2 道**，重点维度 4–6 道。
- 难度分布约 **★:★★:★★★ = 3:5:2**。
  - ★ 概念题：判断是否听说过这个概念
  - ★★ 机制题：判断是否理解运作方式
  - ★★★ 后果题：判断是否知道「这件事会导致什么」——这一档最能区分真懂假懂
- 多选题占 15–25%，用 `multi: true`，得分按 `(命中 − 误选) / 正解数` 计算，可得部分分。

## 3. 每道题的写法

```js
{
  cat: "维度key", level: 2, multi: false,
  text: "题干，可含行内 HTML：<code>示例代码</code>",
  opts: ["选项 A", "选项 B", "选项 C", "选项 D"],
  answer: [1],                      // 索引数组
  why: "解析：<b>为什么</b>是这个答案，以及<b>这一点对完成任务的具体影响</b>。"
}
```

**关键要求：`why` 必须写成「这一点对任务的影响」，而不是教科书式定义。**
测评本身就是第一课 —— 学习者提交后逐题读解析，是整套教程中信息密度最高的一段。

- ✗ 只陈述事实：`why: "这个操作是异步的。"`
- ✓ 事实 + 后果 + 指向后续：`why: "这个操作是异步的，所以你此处量到的不是真实耗时；这直接决定了后面要用 X 手段而不是 Y 来测量。"`

## 4. 干扰项设计

干扰项要对应**真实的误解**，不要凑数。好的干扰项被选中时，你就知道学习者的心智模型错在哪。

做法：针对每道题，先想「新手在这里最常见的错误认知是什么」，把它写成一个看起来合理的选项。
一旦学习者选中它，你就能预判他在后续某个具体场景会犯什么错，从而在课程里提前纠正。

## 5. 除选择题外必须包含的两部分

**自评滑块（`SELF`）** 0–5 分，覆盖比选择题更宽的范围（相关语言/工具的熟练度、
是否读过相关源码、是否从头做过同类项目）。它和选择题结果**对照**着看最有价值：

- 自评高 + 答错 → 有盲区，或概念名词对不上（要先统一术语）
- 自评低 + 答对 → 有直觉但不自信（可以讲快一点）

**实际处境（`CONTEXT`）** 自由填写，通常 3–5 项。这是最容易被忽略但影响最大的部分，
按任务不同灵活设计，但通常应覆盖：

- 目标场景（任务的具体分叉方向；有没有明确的对象/业务）
- 环境约束（能装什么、能不能改动源码/上游、有哪些硬件或权限）
- 最终交付形态（一次性分析 / 可复用工具 / 提交给上游 / 只是读懂）
- 可投入时间与期限

**没有这部分，生成的课程一定会跑偏**：例如把大量篇幅花在一个方向，而对方走的是另一个分叉。

## 6. 评分与档位

- 单选：对 1 分，错 0 分，**留空 0 分但要在结果里单独标注「未作答」**（留空 ≠ 答错，
  它意味着「知道自己不知道」，比乱猜更有信息量）。
- 多选：`max(0, (命中 − 误选) / 正解数)`。
- 维度得分 = 该维度得分和 / 题数，映射到 扎实(≥80%) / 半懂(≥55%) / 薄弱(≥30%) / 空白。
- 总分映射起点档位，用来决定第一节课从哪讲起。

## 7. 出题时的自查

- [ ] 每道题都能回答「答错说明他缺什么、我该补哪一节」
- [ ] 有至少 2–3 道题的答案**直接就是任务的关键技术选型**（答错了正好在开篇纠正）
- [ ] 没有靠记忆版本号、API 参数名这类无意义的题
- [ ] 题干里不暗示答案（选项长度、措辞肯定程度要接近）
- [ ] 解析里的结论后面会在课程正文中被展开，不留悬空
